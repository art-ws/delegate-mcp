## Fixture materialization rules

- `contract-vectors.json`: every `input` is a complete DecisionArgs. The positive primitive/boundary/structured cases contain valid state and questions; each negative changes only its stated boundary while all other required fields stay valid. For generated 255/256-entry criteria, the listed `criteria` object is the exact materialized input (keys `c0`…`c254` / `c0`…`c255`); no hidden base merge is used. `expected_form_valid` is case metadata beside `input`. `V-UNKNOWN-API-KEY-ARG` is only a form-validation control.
- `semantic-vectors.json`: each assessment has complete `prepared_args` and an `assessment_input` naming its exact question, policy, and answer; `expected` supplies status/value/reasons or INVALID_ARGUMENT. `A-POLICY-VALID-ID` is the form-valid existing-ID positive; `A-POLICY-BAD-ID` changes only that map key to absent-question and fails at prepare semantic validation; `A-POLICY-BAD-TYPE` uses existing `q-choice` with a form-valid Noul rule and fails the prepare type match.
- `R-FULL-VALID-BASELINE` is the complete response baseline. Its `q-choice` criteria and answer/probabilities use yes/no; Noul, Score expectation/legend, required usage counts, and optional cost are valid. Every response case repeats a complete request/response and names `baseline_id` plus `changed_json_paths`; negative cases alter only their named boundary. The valid minimal and unknown-extra cases are separate controls. `mutation_recipe` never asks an adapter to infer hidden fields. The valid baseline has required usage counts. The intentionally wrong/missing ID/type/field/value cases expect UPSTREAM_PROTOCOL.
- `R-OUT-OF-RANGE-NONFINITE` uses JSON numeric 1.1 as the materialized out-of-range case. Companion direct-call control must construct `Number.NaN` and `Number.POSITIVE_INFINITY` in memory after parsing valid JSON; JSON text itself cannot encode these values.
- The previous incorrect A-CHOICE-AND-FAIL values are retained under `superseded_attempts` with status `INVALID_EXPECTED_OUTCOME_NOT_COVERAGE`; they are not counted as a passing or failing vector.
